# 指标定义、假设与局限

## 数据与缺失值

输入为复权收盘价宽表：行是交易日期，列是资产，元素 `P(i,t) > 0`。日期按升序排列且必须唯一。价格缺失值只按界面选定的策略处理；收益计算使用 `pct_change(fill_method=None)`，绝不隐式前向填充。

逐资产绩效指标删除该资产的缺失收益后计算，并使用其实际有效观测数年化。相关与协方差矩阵采用所有资产均有收益的共同日期（完整案例法），避免各矩阵元素使用不同样本导致难以解释，但这可能明显缩短样本。组合优化中的预期收益也使用这组完全相同的共同日期，禁止把不同样本估计的收益向量与协方差矩阵混合。

## 收益率

- 简单收益：`r_t = P_t / P_(t-1) - 1`。
- 对数收益：`g_t = ln(P_t / P_(t-1))`。
- 累计简单收益：`R_(1:T) = ∏(1 + r_t) - 1`。

简单收益可用于财富复利和组合加权；对数收益可相加，但横截面组合不能直接按对数收益做线性加权。当相邻任一价格缺失时，该期收益也缺失。

## 年化绩效

令 `N` 为有效收益观测数，`A` 为每年周期数（默认 252）：

- 几何年化收益：`(∏(1+r_t))^(A/N) - 1`。
- 年化波动率：`sample_std(r_t) × sqrt(A)`，样本标准差使用 `ddof=1`。
- Sharpe：`(几何年化收益 - 年化无风险利率) / 年化波动率`。
- 下行偏差：`sqrt(mean(min(r_t-r_f,daily, 0)^2)) × sqrt(A)`。
- Sortino：`(几何年化收益 - 年化无风险利率) / 年化下行偏差`。
- Calmar：`几何年化收益 / |最大回撤|`。

界面中的无风险利率是有效年利率，日无风险利率为 `(1 + rf)^(1/A) - 1`。这里采用几何年化收益作为 Sharpe 分子，和部分教科书采用“日均超额收益 × A”的定义不同；跨系统比较前必须统一口径。

波动率假设周期尺度可用平方根法则缩放，这隐含收益独立同分布近似。Sharpe/Sortino 对非正态、序列相关和短样本敏感；分母为零时没有定义。

## 回撤

财富指数 `W_t = ∏_(s≤t)(1+r_s)`，运行峰值 `M_t = max(1, W_1, ..., W_t)`，回撤 `D_t = W_t/M_t - 1 ≤ 0`。最大回撤是样本内最小的 `D_t`，区间从此前财富峰值到谷值。若序列第一期便下跌，峰值是样本开始前的初始净值 1，代码以空峰值日期和明确标记表示，不伪造交易日期。回撤依赖观察区间，不能代表样本外最坏损失。

## VaR 与 CVaR

单周期损失定义为 `L_t = -r_t`，因此结果中的正数代表损失、负数代表盈利。置信水平 `c` 下：

- 历史 VaR：`quantile(L, c)`。
- 历史 CVaR / Expected Shortfall：样本中 `L_t ≥ VaR_c` 的损失均值。

当前方法不做分布拟合和时间加权，完全依赖历史样本；小样本、结构变化和样本外极端事件会使估计不稳定。CVaR 的离散样本尾部定义可能与带分位点插值权重的实现略有不同。

## 协方差与组合风险

样本协方差按完整共同收益日计算，再乘 `A` 年化。组合波动率：

`σ_p = sqrt(w' Σ w)`。

波动率的边际贡献 `MRC_i = (Σw)_i / σ_p`，资产风险贡献 `RC_i = w_i × MRC_i`，且在数值误差范围内 `Σ RC_i = σ_p`。百分比风险贡献为 `RC_i / σ_p`；有负权重或对冲效应时它可能为负。

## 最小方差优化

当前默认禁止做空，求解：

```text
minimize    w' Σ w
subject to  sum(w) = 1
            0 ≤ w_i ≤ max_weight
```

由 CVXPY 建模并交给 CLARABEL（或 SCS）求解。输入协方差必须有限、对称且半正定。程序不静默裁剪用户最大权重；若 `资产数 × max_weight < 1`，直接判定不可行。求解后再次检查权重和、上下界及目标收益残差；超出与求解状态匹配的容差时直接报错。允许做空时必须显式提供权重下限，防止形成没有杠杆边界的问题。样本协方差估计误差可能使最优权重不稳定，最小方差并不等于最小实际损失。

### 目标收益率与有效前沿

当前实现中，`μ` 的每一项是相同共同完整收益样本上的**逐资产历史几何年化收益**：`μ_i = (∏(1+r_i,t))^(A/N) - 1`。这与经典均值—方差模型常用的 `mean(r_i) × A` 算术年化向量不同。界面中的组合“年化收益”是 `μ'w` 的加权代理值，不等于组合收益序列的实际几何年化收益，也不是未来收益预测。给定目标年化收益率 `μ*` 时，在上述约束中增加：

```text
            μ'w ≥ μ*
```

因为目标约束采用“不低于”而非严格等于，若全局最小方差组合已超过目标，它仍是该问题的最优解。界面显示的目标残差为 `μ'w - μ*`。

禁止做空且每项权重不超过 `max_weight` 时，可行收益上下界是在线性约束下分别最小化和最大化 `μ'w` 的结果。实现按预期收益从低到高或从高到低依次分配权重，得到与线性规划相同的极值；若资产数与最大权重无法使权重和达到 1，则直接报错。

有效前沿从全局最小方差组合的预期收益开始，到最大可行收益之间建立目标网格，并对每个目标独立求解最小方差问题。图中横轴为年化波动率，纵轴为年化预期收益。任一点求解失败都会报告目标和求解状态，不会跳过失败点或静默调整约束。

该前沿是以历史几何年化收益向量作为收益代理的样本内约束优化结果，不包含参数估计误差、交易成本、流动性、税费和尾部风险。短样本和极端收益会显著影响年化估计，因此前沿不应解释为未来业绩保证，跨工具比较时应先统一收益向量口径。

## 滚动回测

输入是按日期严格升序、日期唯一、且所有资产均为有限值的简单收益率矩阵。界面把价格计算得到的共同完整收益日明确传给回测引擎；引擎不会自行前向填充或删除日期。

令训练窗口长度为 `L`。决策位置 `d` 只使用：

```text
returns[d-L+1 : d]
```

其中包含决策日 `d`，但不包含下一期。目标权重从 `d+1` 的收益开始生效，并在每隔指定持有期数后重新估计。时序审计表记录 `training_start`、`training_end`、`decision_date` 和 `application_date`，始终要求 `application_date > decision_date`。

调仓前权重是上一期收益作用后的自然漂移权重。若目标权重为 `w*`，调仓前权重为 `w-`，成交名义金额比例定义为：

`turnover_t = Σ_i |w*_i - w-_i|`。

买入和卖出分别计入，因此它不是除以 2 的单边换手口径。首次从现金全额建仓时该比例为 1。固定比例成本率为 `c` 时：

`cost_t = c × turnover_t`。

若目标权重作用下的当期组合毛收益为 `r_p,t`，扣费后的净收益为：

`r_net,t = (1 - cost_t)(1 + r_p,t) - 1`。

收益作用后，下一期调仓前的自然漂移权重为：

`w-_i,t+1 = w*_i,t(1+r_i,t)/(1+r_p,t)`。

买入持有基准在样本外第一期按等权完成一次建仓，之后只让权重随资产收益自然漂移，不再平衡；初始建仓使用与策略相同的交易成本率。

当前模型假设可在下一期开始时按给定价格完成全部调仓，仅包含与成交名义金额成比例的成本，不模拟买卖价差变化、市场冲击、税费、成交量限制、现金利息或停牌。它适合教学和低频组合研究，不代表真实可成交业绩。
